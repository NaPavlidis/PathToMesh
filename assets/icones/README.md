# Ícones do PathToMesh

| Arquivo | Imagem | Onde é usado |
| --- | --- | --- |
| `3.ico` / `3.png` | Só o símbolo (a curva virando malha), sem texto | Janela do **app** (barra de título, barra de tarefas e janelas de configurações) |
| `2.ico` / `2.png` | Símbolo + "PathToMesh" na horizontal | Janela do **launcher** |
| `1.ico` / `1.png` | Símbolo com "PathToMesh" embaixo | **Instalador e atalhos** (Área de Trabalho e Menu Iniciar) |

As janelas usam o `.ico` (`iconbitmap`); se ele faltar ou não puder ser lido (fora do Windows), usam o `.png` (`iconphoto`). A escolha fica em `ICONES`, no `tema_janela.py`.
